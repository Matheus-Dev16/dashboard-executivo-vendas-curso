# 📊 Dashboard Executivo de Vendas de Cursos

Este repositório contém um **Dashboard interativo desenvolvido no Microsoft Excel**, projetado para monitorar e analisar o desempenho de vendas, faturamento e performance de cursos e instrutores em múltiplos países e idiomas.

## 🎯 Objetivos do Projeto

- **Acompanhamento Financeiro:** Monitorar o faturamento total da instituição com base no volume de vendas e preço dos cursos.
- **Análise Geográfica e Linguística:** Mapear o desempenho comercial segmentado por **país** de entrega e **idioma** da instrução.
- **Desempenho por Instrutor e Cursos:** Identificar os professores com maior receita gerada e os cursos mais procurados.
- **Interatividade Visual:** Permitir filtros dinâmicos sincronizados em múltiplos gráficos e tabelas para tomada de decisão em tempo real.

---

## 🛠️ Funcionalidades Técnicas & Estrutura

1. **Separação em Camadas:**
   - `Tabela`: Base de dados bruta com as transações (Data, Curso, Instrutor, País, Preço, Vendas, Categoria e Idioma).
   - `Apoio_Dashboard`: Camada de processamento intermediário utilizando **Tabelas Dinâmicas** para consolidação de métricas.
   - `Dashboard`: Camada visual com design executivo e gráficos dinâmicos.

2. **Ferramentas do Excel Utilizadas:**
   - Tabelas Dinâmicas (Pivot Tables)
   - Gráficos Dinâmicos (Colunas, Barras, Rosca/Pizza)
   - Segmentação de Dados (Slicers) conectadas via Conexões de Relatório
   - Formatação executiva e limpeza de elementos visuais

---

## 📁 Como Utilizar

1. Faça o download do arquivo [`Dashboard Excel - Curso.xlsx`](./Dashboard%20Excel%20-%20Curso.xlsx).
2. Abra o arquivo no **Microsoft Excel**.
3. Navegue até a aba **`Dashboard`**.
4. Utilize os filtros de **Segmentação de Dados** para explorar os indicadores por país, idioma e tipo de manutenção/curso.
